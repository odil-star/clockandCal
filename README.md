# Clock & Calculator

Часы и калькулятор в одном интерфейсе. React + Vite.

## Возможности

**Часы**
- Живое время с точностью до секунды
- Дата с днём недели
- Индикатор заполнения текущей минуты

**Калькулятор**
- Ввод мышью и с физической клавиатуры: `0–9`, `+ − * /`, `.` и `,`, `Enter` — результат, `Backspace` — стереть, `Esc` — сброс
- Разделение разрядов прямо при наборе: `10000+5000` → `10 000+5 000`
- Промежуточный ответ пересчитывается на каждое действие
- Округление результата — без хвостов вида `0.30000000000000004`
- Размер шрифта подстраивается под длину выражения

**Интерфейс**
- Адаптив: на десктопе два блока рядом, на узких экранах часы становятся нижней частью карточки калькулятора
- Поддержка `prefers-reduced-motion`

## Запуск

```bash
npm install
npm run dev
```
